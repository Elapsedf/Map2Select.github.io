02 / THE IDEA

Let the map guide the budget.

Preserve road context while keeping the feature diversity needed to understand a scene.

Driving scenes contain many visual tokens, but their value is uneven. Map2Select projects map semantics into the camera views, uses them to weight visual features, and selects a compact set of representative tokens.

  1. 1

    Project map context

    Connect road and map elements to the visual token grid through the camera geometry.

  2. 2

    Weight semantic coverage

    Combine map guidance with visual feature diversity to represent the scene.

  3. 3

    Select within a budget

    Allocate tokens across views and pass the retained set to the driving VLM.
